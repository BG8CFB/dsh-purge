# 蓝队防守 3 分钟上手

> 蓝队与红队是**两条平行线**：一次攻防里你只担任一侧。担任蓝队就建防守项目、用蓝队工具、看「蓝队值守台」；红队那条线一行不受影响，两边数据互不可见（复盘时由你在面板做一次只读对账）。

## 1. 建项目（责任区）

左侧栏「破甲」→ **蓝队值守台** → **项目中心**：

- 名称：防守单位 / 责任区（如「某某集团 · 生产区」）
- 责任 CIDR：如 `10.20.0.0/16`（AI 只在这个范围里做资产与检测）
- 模式：演练 / 实战
- SLA 档：`standard`（P0 5 分钟研判 / 30 分钟止血）

项目 = 目录 = DSH 工作区，库在 `$DSH_HOME/blueteam/engagements/<id>/assets.db`。

## 2. 进入防守

点项目行上的 **进入防守**：切到该项目工作区，开一个「蓝队模式」会话。
会话里是防守指挥 + 四个可派的技术角色：

| 角色 | 干什么 |
| --- | --- |
| `asset` | 导资产、打画像、跑基线、登漏洞、收暴露面 |
| `detection` | 登记数据源、写检测规则、看 ATT&CK 覆盖 |
| `triage` | 告警研判、升事件 |
| `responder` | 提处置、执行中低危、验证、写事件时间线 |

你直接说人话：**「先看现在的摘要」**、**「把这份资产清单导进去」**、**「把这条告警判掉」**、**「这个 Redis 未授权怎么修」**。

## 3. 开局三件事（面板或对话都行）

1. **导资产**：资产测绘 → 右侧导入框贴 JSON 数组：
   ```json
   [{"ip":"10.20.1.10","name":"oa","owner":"行政部","business":"OA","criticality":"P0"}]
   ```
   **criticality 必填**（P0 核心 / P1 重要 / P2 一般 / P3 边缘）。
2. **接数据源 + 写规则**：检测覆盖 → 登记 EDR/WAF/DNS/主机日志（状态 connected），再写至少一条针对关键 TTP 的规则。
   没有 connected 的数据源，覆盖矩阵全是红色盲区。
3. **跑基线**：资产测绘 → 点开一台资产 → 底部基线登记（账号/端口/补丁/配置/日志/备份）。**fail 会自动生成暴露面**。

## 4. 告警从哪来

- 让智能体接入：给它 CSV/JSON，它调 `blueteam_alert_ingest`；
- 手工造一条（验证链路）：面板或工具传一行；
- 真实 SOC：把 EDR/SIEM 导出按字段映射成行（`source/rule_code/severity/title/entity_id/first_seen`）。

接入时自动：白名单抑制 → 10 分钟去重合并 → 风暴折叠（同一规则 60 秒超 100 条只留代表 + 一条风暴告警）。

## 5. 研判（告警台，最高频）

左列队列（j/k 上下），右侧详情：

- **真警** → 先「升为事件」（填标题/级别），系统自动建事件并挂接；
- **误报** → 选原因（规则误报 / 未知资产 / 业务变更 / 时钟漂移 / 其它），必须给原因；
- **重复** → 填原告警 id；
- **待查** → 标 pending，写清还缺什么证据。

## 6. 处置（事件处置）

1. 选事件 → 提处置动作（`isolate_host` / `block_ip` / `kill_process` …）。
2. **高危动作（隔离主机 / 禁用账号 / 改密 / 吊票据）只进「待批」，由你在面板批准**——AI 没有审批工具。
3. 批准 → **执行** → **验证**（贴证据：连通性对比 / EDR 状态 / 旧凭据失效）。
4. 有已验证动作后，事件才能推进到「已止血」；再「已清源」「已恢复」「已关闭」。
5. 动作执行后 30 分钟是冷静期：打错了点「回滚」。

## 7. 漏洞（技术账）

漏洞页（左列表 + 右详情）：登记 → 按严重级排 → 修完标 fixed 并写证据；复测不成立标误报。
来源三处：自查扫描、红队打穿的入口、事件暴露的入口。

## 8. 复盘对账（红蓝交手证据）

报告与复盘 → **红蓝对账**：填红队项目 id → 逐条对比红队攻击步骤与蓝队告警/事件（±15 分钟）→ `命中 / 迟报 / 漏报 / 不可判定`。
红队库**只读**打开、只由你在面板触发；模型只能读结果。

## 9. 数据在哪 / 怎么删

```
$DSH_HOME/blueteam/
  engagements/<id>/assets.db     资产、漏洞、暴露面、告警、事件、动作、对账
  engagements/<id>/agents/*.md   角色提示词（可改）
  skills/                        随包技能
```

删除项目 = 删目录 + 库 + 工作区，不可恢复。红队目录不受影响。

## 10. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 模式下拉里没有「蓝队模式」 | 预设未注册：重启宿主一次；仍不行看 `$DSH_HOME/blueteam/preset-declare.json` 的 `broken` 字段 |
| 对话里工具不存在 | 会话不是蓝队模式：从「蓝队值守台 → 进入防守」重开一个会话 |
| 告警台一直空 | 没接数据源或没 ingest：先去「检测覆盖」看日志源状态 |
| 高危动作执行被拒 | 未审批：去「事件处置」批准，或让值班长在面板发起 emergency（要写理由） |
| 事件推不进「已止血」 | 动作没验证：先验证（贴证据） |
| 蓝队面板看到红队项目 | 不会发生：两条线库不同、工具不同、页签不同；只能在对账里看到红队的**只读**结果 |
