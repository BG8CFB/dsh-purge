# 怎么用：红队演练

## 一句话

在破甲里建一个项目 → 它自动变成左侧栏的一个工作区（「攻防演练 · 某某」）→ 点「进入演练」就进到这个工作区的红队会话里，直接说话。

**不再有“生成开场白 → 让你按回车”这一步。**

---

## 第一次：建项目并进入

1. 左侧栏「破甲」→「指挥台」。
2. 顶部「开工检查」确认红队模式预设是绿色「已注册」（红色点「修复并重新注册」）。
3. 在「进入演练」卡的下半部分填：项目名称（必填）、授权 CIDR（可空）、目标说明（可空）。
4. 点「**新建项目并进入**」。

结果：

- 磁盘上出现 `$DSH_HOME/redteam/engagements/<项目>/`（assets.db、agents、runs、reports 都在里面）；
- 左侧栏出现工作区「攻防演练 · 项目名」；
- 直接进入该工作区的一个红队模式会话，光标在输入框，你说第一句就行。

---

## 之后：随时回到这个项目

破甲 → 指挥台 → 选项目 →

- **进入演练**：切到该项目工作区并打开它的会话；
- **新建对话**：在同一工作区再开一个红队会话；
- 也可以在左侧栏那个工作区里直接点「新建会话」——但记得模式选「红队模式」，否则拿不到红队工具。

同一项目的所有会话都在那个工作区下面，不会散落在默认工作区。

---

## 子智能体：你不需要“调用”

红队模式 = 1 个指挥 + 5 个执行角色，指挥用 subagent 工具自己派：

| 角色 | 职责 |
| --- | --- |
| recon 信息收集 | 子域 / 端口 / 指纹 / 资产测绘 |
| assess 资产梳理 | 给资产排优先级 |
| vuln-scan 漏洞发现 | 查 POC、扫漏洞、验证 |
| exploit 漏洞利用 | 拿权限、WebShell、搭隧道 |
| internal 内网渗透 | 走隧道横向、提权、打集权系统 |

你说的话就是任务书：「现在打到哪了？」「让漏洞发现先打 10.0.0.5」「出报告」。

---

## 删除项目

指挥台选项目 →「删除项目」，或项目卡片上的「删除项目」。
会删掉项目目录（资产库、报告全在内）+ 对应工作区 + 会话绑定，**不可恢复**，有二次确认。

归档仍可用，但收进了卡片「编辑」里面，不再是主按钮。

---

## 多项目并行

一个项目 = 一个工作区 = 一个目录 = 一个 assets.db，互不串写。
知识库（POC / nuclei 模板）是全局的，跨项目共享；项目里验证过的 EXP 用 redteam_poc_add 回填。

---

## 排错

| 现象 | 处理 |
| --- | --- |
| 模式胶囊没有「红队模式」 | 指挥台 →「修复并重新注册」；或彻底退出 DSH NEXT 再开 |
| 点进入演练没反应 | 看开工检查里「工作区」是否就绪；项目卡片显示「将自动创建」时点一次进入即补建 |
| 说“尚未绑定靶标” | 回「绑定到项目 X」，或项目头点「绑定本会话」 |
| 子智能体不出来 | 看并发上限（默认 3）与 redteam_preflight 的环境检查 |
